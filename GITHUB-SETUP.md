# GitHub — ABM Radar Plus

Canonical repository: https://github.com/ArioBarzanMoradi/ABM-Radar-Plus

The maintained app is at repository root. Commit source and prebuilt `docs/assets/app.js` and `style.css`; never commit operational configuration, database files, keys or real panel URLs. The old nested application trees are removed from the working tree while git history remains intact.

The workflow **Validate ABM Radar Plus** typechecks, builds, runs Python integration tests and shell syntax checks, and creates a ZIP artifact. It runs on Ubuntu 24.04. See `VERIFICATION.md` for the difference between the isolated installer harness and deployment on real systemd hosts.

To publish the public project website, select **Settings → Pages → Deploy from a branch → main → /docs**. Pages contains only the project website and screenshots of a fresh empty installation. It does not run Python or access the private panel. After a repository rename, verify the published URL in Pages settings.

For a tagged release, create a real tag on a reviewed commit, use the matching `VERSION`, and attach `dist/abm-radar-plus-github-ready-v2.0.0.zip` generated by `python3 scripts/package.py`. The updater accepts `--ref TAG`; a tag must exist before operators use it. Default updates follow `main`.
