پایش واقعی سرور

عامل لینوکس مصرف CPU، حافظه و پورت‌های محلی را می‌خواند. هر میزبان کلید اتصال جداگانه دارد.

عیب‌یابی از همان مبدأ

پینگ، DNS، مسیر و پورت را از سرور انتخابی امتحان کن. نتیجه کنار تاریخچهٔ رخدادها و یادداشت‌های آن می‌ماند.

دمو در مرورگر

۱۲ سرور نمونه برای امتحان‌کردن جدول، نمودار، هشدارها و چک‌لیست‌ها آماده‌اند. تغییرات دمو در همین مرورگر ذخیره می‌شوند.

پنل مرکزی

مخزن را روی یک VPS دریافت کن و از داخل پوشهٔ آن نصب‌کننده را اجرا کن. نام کاربری و گذرواژهٔ مدیر را همان‌جا تعیین می‌کنی.

sudo bash install.sh

پنل روی 127.0.0.1:8787 گوش می‌دهد. دستور اتصال SSH در پایان نصب چاپ می‌شود.

عامل هر سرور

میزبان را در پنل ثبت کن، از «اتصال عامل لینوکس» کلید بگیر و روی همان میزبان فرمان زیر را اجرا کن.

sudo bash install-agent.sh

برای اتصال از سرور دیگر، از نشانی HTTPS پنل یا تونل SSH استفاده کن. راهنمای هر دو روش در README مخزن است.
