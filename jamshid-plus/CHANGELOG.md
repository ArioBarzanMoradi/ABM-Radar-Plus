# Changelog

## 1.1.0 — 2026-11-07

- Renamed the interface and project to Jamshid Plus (جمشید پلاس).
- Removed the seeded fleet, synthetic readings, simulated diagnostics and public demo.
- Added the Jamshid charcoal / ivory glass interface and persistent system appearance.
- Added a first-server onboarding screen and clearer per-host agent enrollment with copy.
- Added Switzerland, Canada, Netherlands, France, UK, Finland, UAE, Singapore and Other.
- Added host deletion with agent revocation and atomic cleanup of tunnel peer references.
- Changed new-install loopback default to port 8788; existing configured ports remain.
- Added jamshidctl, while preserving existing radarctl and installation state paths.
- Prepared a Persian GitHub project page, README, screenshots, CI and repository guides.
