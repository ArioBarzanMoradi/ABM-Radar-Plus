# دامنه، HTTPS و WebPath در ABM Radar Plus

نصب پیش‌فرض روی `127.0.0.1:8788` است. Nginx روی یک پورت آزاد مانند ۱۰۴۴۳، اتصال HTTPS را می‌گیرد و مسیر انتخابی را به پنل می‌فرستد. پورت ۴۴۳ می‌تواند در اختیار VPN فعلی بماند. پورت نمونه را با پورت آزاد واقعی خودت جایگزین کن.

اگر پنل همین حالا با دامنه و WebPath کار می‌کند، برای ارتقا این تنظیمات را دوباره اجرا نکن؛ `abm-radarctl update` آن‌ها را حفظ می‌کند.

## نصب تازه

رکورد DNS دامنه باید به سرور برسد. Nginx و گواهی معتبر همان دامنه لازم‌اند. اگر Nginx نصب نیست، با درنظرگرفتن سرویس‌های فعلی خودت آن را نصب کن:

```bash
sudo apt install -y nginx certbot
```

اگر گواهی معتبر داری، از همان استفاده کن. اگر پورت ۸۰ واقعاً آزاد و از اینترنت قابل دسترس است، helper بدون متوقف‌کردن سرویس موجود گواهی می‌گیرد:

```bash
sudo bash enable-ssl.sh radar.example.net
```

اگر وب‌سرور فعلی روی ۸۰ مسیر challenge را سرو می‌کند، از webroot **همان سایت** استفاده کن:

```bash
sudo bash enable-ssl.sh radar.example.net --webroot /var/www/html
```

اگر ۸۰ قابل دسترس نیست، روش DNS challenge را با certbot و ارائه‌دهندهٔ DNS خودت انجام بده. helper سرویس‌های روی ۸۰ یا ۴۴۳ را متوقف نمی‌کند. دریافت و تمدید گواهی به وضعیت DNS/شبکه و روش challenge بستگی دارد؛ پس از تنظیم تمدید، `sudo certbot renew --dry-run` را بررسی کن. حالت standalone هنگام تمدید نیز به پورت ۸۰ آزاد نیاز دارد.

برای پیکربندی پنل با مسیر دلخواه:

```bash
sudo bash configure-web.sh --domain radar.example.net --port 10443 --path /abmradar/
```

URL نمونه: `https://radar.example.net:10443/abmradar/`. فایل‌ها و پورت‌های واقعی سرورت را جایگزین کن. مسیر باید به `/` ختم شود و از حروف انگلیسی، عدد، خط تیره و زیرخط ساخته شود. `--upstream-port` برای پنل با پورت داخلی متفاوت است. `--cert` و `--key` مسیر فایل‌های گواهی سفارشی را می‌پذیرند.

helper پیکربندی Nginx را با `nginx -t` بررسی و `RADAR_PUBLIC_ORIGIN` را فقط با scheme، دامنه و پورت بیرونی می‌نویسد؛ WebPath داخل این متغیر قرار نمی‌گیرد. Nginx پیشوند مسیر را با `proxy_pass` دارای slash پایانی حذف و cookie path را محدود می‌کند. پورت TCP انتخابی باید در فایروال سیستم و ارائه‌دهندهٔ سرور قابل دسترس باشد؛ helper فایروال را تغییر نمی‌دهد.

## عامل و پیوند پنل

- عامل همان میزبان: `http://127.0.0.1:8788` و کلید عامل همان پنل.
- عامل راه‌دور یا پیوند پنل: URL کامل HTTPS با پورت و WebPath، مانند `https://radar.example.net:10443/abmradar/`.
- برای عامل، کلید عامل لازم است؛ برای پیوند، کلید شبکهٔ صادرکننده. این کلیدها قابل جایگزینی با هم نیستند.

گواهی باید با نام دامنه مطابقت داشته باشد. خاموش‌کردن اعتبارسنجی TLS یا دنبال‌کردن redirect حامل کلید، بخشی از این برنامه نیست. اگر WebPath را تغییر می‌دهی، URL عامل‌های راه‌دور و پیوندهای پنل‌های دیگر را نیز به‌روز کن.
