# تطبیق امکانات رادار قبلی با ABM Radar Plus 2.0

این فهرست از README و کد اصلی رادار نسخهٔ ۱.۱ استخراج شده است. امکانات در معماری عامل و پنل Plus پیاده‌سازی شده‌اند؛ نیازی به اجرای هم‌زمان backend قبلی نیست.

| قابلیت قبلی | جایگاه در نسخهٔ جدید |
|---|---|
| CPU و RAM | داشبورد، جزئیات سرور و تاریخچهٔ SQLite |
| Disk، uptime، load و hostname/OS | تب سلامت و شبکه، اطلاعات واقعی عامل |
| نرخ ورودی/خروجی و مجموع رابط‌ها | کارت ترافیک، جدول رابط‌ها، نمودار ترافیک |
| رابط IPv4/IPv6، UP و رابط پیش‌فرض | جدول رابط‌ها و آدرس‌ها |
| Default route IPv4/IPv6 و resolver | مسیرهای پیش‌فرض و DNS سیستم |
| TCP/UDP listen، Bind و family | جدول پورت‌ها با فیلتر؛ مستقل از پورت‌های دلخواه ثبت‌شده |
| شناسایی سرویس VPN و رابط تونل | کشف systemd و رابط‌ها، همراه با قواعد اختصاصی عامل |
| مقصدهای خروجی و TCP/Ping مستقل | تنظیم حداکثر ۲۴ مقصد در همان صفحه؛ زمان نمونه مشخص |
| DNS/HTTPS/IPv4/IPv6/ICMP/STUN | پروب‌های دوره‌ای اختیاری؛ تست دستی typed در عیب‌یابی |
| ورود، WebPath و HTTPS | نشست مدیر و Nginx با مسیر دلخواه، SSL helper |
| تغییر نام/رمز، بستن نشست‌ها و show | `abm-radarctl username / passwd / rotate-sessions / show` |
| پوستهٔ زغالی/استخوانی و فونت محلی | حفظ هویت بصری در تمام صفحه‌ها |

load، hostname و OS در اطلاعات سلامت همین میزبان نمایش داده می‌شوند. مصرف دیسک مربوط به filesystem ریشه است؛ مجموع ظرفیت همهٔ دیسک‌ها نیست. شنود محلی، بازبودن ورودی اینترنت یا کارکرد VPN را تضمین نمی‌کند.

فراتر از نسخهٔ قبلی: چند پنل مستقل با کش مقاوم به قطعی، عامل اختصاصی هر سرور، صف تست با شناسهٔ تکرارپذیر، تاریخچه تا ۷ روز، هشدار و رخداد پایدار، چک‌لیست، یادداشت، backup آنلاین SQLite و به‌روزرسانی روی سرور اضافه شده‌اند. ثبت سرور نمونه یا ساخت دادهٔ نمایشی در نصب واقعی وجود ندارد.
